# MSU “Lomonosov” Physics Olympiad — source links

The current guide contains **Lomonosov 2020/21, 2021/22, 2022/23, 2023/24 and 2025** collections, alongside related MSU competitions. The broader MSU publication trail also contains older Lomonosov problem/solution material.
